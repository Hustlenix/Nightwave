## Check results and limits

The 2026-10-05 routing closure fixes charger I2C/interrupt clearances and a
power-switch-control crossing, connects manufacturer-recommended BM83 ground
lands 56/57, and preserves the complete antenna exclusions. 209 power-trace
sections were widened using native copper-shape collision tests; this is not
a thermal or loop-stability qualification. Three non-plated M2 mounting holes
have 5 mm copper-free regions. Functional silkscreen identifies the controls,
headers, battery polarity and the review-only revision.

Fresh local project validation and all 34 Python tests passed. The six reference
regression tests include connector-vs-load MPN identity, BM83 supply/ground
land constraints, amplifier exposed-pad grounding and reserved PSRAM pins.
Current ERC/DRC/parity reports and source hashes are in the reference package.
ERC uses passive electrical pin types and must not be presented as a full
electrical review. New CI results, when available, are revision-specific.

Read the generated `VALIDATION_STATUS.md`, `reports/drc.rpt` and
`reports/validation.json` for the actual exported revision. Never infer a clean
route from a rendered image. The schematic block-symbol pins are passive:
zero ERC checks connectivity only, not driver conflicts or power-pin types.
DRC/parity cannot establish circuit functionality.

The router uses 0.2 mm signals and 0.6 mm nominal power classes, with narrower
escape/retry routing. Ground/3.3 V pours and all-layer antenna exclusions are
included when generated by the routing helper. Every power neck-down must be
reviewed for length, current density and drop; its presence is not an approval.
USB pair impedance and switch-mode loop layout are not digitally signed off.

## Before fabrication or grant submission

The PCB is a review checkpoint, not an approved production board. Close the
reference's `REVIEW_CHECKLIST.md`, including:

- USB source-current policy before enumeration, input inrush, ESD and differential impedance.
- Charger defaults/configuration, TS network, pack polarity/protection/current rating and thermal/current review.
- Manufacturer land patterns, mask/paste rules, pin-one orientation and assembly capability.
- BM83 firmware provisioning, clock direction, voltage levels and radio keepouts.
- Display connector mating and cable wiring; the selected TFT is an off-board module.
- Mounting, connector/card access, board thickness and an editable enclosure matching the pack and board.
- Reconciliation with the reference GPIO map; TFT/BT/charger live firmware qualification is not implied.
- Complete procurement BOM: generic passive values are explicitly pending MPN selections. Battery/speaker/display items must be distinguished from their PCB connectors.
- Independent named electrical/layout/mechanical review and the grant's authorship requirements.

`hardware/BOM.csv` and `hardware/product-config.json` still describe the
earlier product-selection/power-screening baseline. They are not a purchase
list or a validated power model for this reference. Do not merge incompatible
candidate footprints from those files into the reference PCB. Final freeze and
recalculation follow reviewed circuit/pack/display integration.

Physical playback, overnight runtime, build photos and demo video remain
later physical-build evidence, not fabricated prerequisites for a digital
design review. No final-device or grant acceptance is asserted here.
